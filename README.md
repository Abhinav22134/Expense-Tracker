💸 Expense Tracker

A full-stack Expense Tracker web application that helps users manage and monitor their daily expenses efficiently. The application provides a secure and user-friendly interface to track income and expenses in real time.

🚀 Features
🔐 Secure user authentication using JWT (Login/Signup)
📊 Add, update, and delete expenses with real-time tracking
📁 Organized dashboard to view transaction history
🔎 Filter and manage expenses easily
🛠️ Tech Stack
Frontend: React.js
Backend: Node.js, Express.js
Authentication: JWT (JSON Web Tokens)
Database: MongoDB
⚙️ Functionality
Built RESTful APIs for handling expense data
Implemented protected routes for secure access
Ensured smooth frontend-backend integration
